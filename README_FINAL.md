# NOBA — نسخهٔ مهندسی 1.7.0

این نسخه برای مرحلهٔ بعدی ساخت APK آماده شده است.

- هفت مسیر اصلی: بلوتوث، گنجینه، آوای نوا، هاله نور، کهکشانی، زهره و اتاق فرمان.
- ظاهر صفحات از هم جداست: تم، پس‌زمینه، فرم کنترل‌ها و انیمیشن‌ها برای هر مسیر هویت مستقل دارند.
- نوار پایین هفت‌تایی ثابت است و روی صفحه‌های اصلی پنهان نمی‌شود؛ اندازهٔ آیکون‌ها برای گوشی‌های باریک نیز واکنش‌گرا شده است.
- هدر هر صفحه یک نشان انتخاب‌شدهٔ ثابت دارد و چرخش آن آرام و گهگاهی است؛ کاربر نمی‌تواند نشان هدر را عوض کند.
- لوگو و آیکون نصب‌شدهٔ برنامه از هویت ثابت نوبا استفاده می‌کنند و برای نسخهٔ توزیعی قفل هستند.
- آوای نوا: پلی‌لیست محلی، قبلی/بعدی، پخش/توقف، نوار پیشرفت، تصویر و افکت زنده و جست‌وجوی پیش‌نمایش موسیقی.
- RGB و کهکشانی: شدت، سرعت، رنگ، افکت‌ها و کنترل‌های فضایی.
- زهره: متن، تشخیص گفتار فارسی، شخصیت‌های مختلف و خروجی گوشی/نوبا به‌عنوان مسیرهای تنظیماتی.
- اتاق فرمان: ظاهر، پس‌زمینه، آیکون‌های نوار پایین، هستهٔ تصویری بلوتوث، صداهای هویتی، رمز، اکولایزر، ماژول‌ها و زیرساخت دوربین آینده.
- اکولایزر آوا دو ظاهر مستقل و انیمیشنی دارد: مدار طیفی و ستون‌های زنده.
- دوربین مجالس: انتخاب کیفیت، ضبط قطعه‌ای و انتخاب محل ذخیرهٔ USB از طریق Android Storage Access Framework.

## Backend
`server.mjs` کلیدهای AI را روی سرور نگه می‌دارد و مسیرهای `/api/chat` و `/api/music-search` و مدیریت رمز مشترک را فراهم می‌کند. جست‌وجوی موسیقی فقط پیش‌نمایش provider را برمی‌گرداند.

## بررسی نهایی
- JSONها معتبر هستند.
- JSX/JavaScript پروژه بدون diagnostic نحوی transpile می‌شود.
- همهٔ assetهای محلی و style referenceهای استفاده‌شده بررسی شده‌اند.
- ZIP نهایی با `unzip -t` سالم است.
- مسیرهای اصلی backend با smoke test بررسی شده‌اند.

## محدودیت‌های آگاهانه
- اتصال واقعی Bluetooth هنوز به کنترلر/ESP32 نهایی وابسته است.
- فرمان‌های Wi-Fi نور و توان به endpoint اسپیکر/ESP32 فرستاده می‌شوند و در backend هوش مصنوعی اجرا نمی‌شوند.
- دوربین ابتدا روی حافظهٔ موقت Android ضبط می‌کند و سپس قطعه‌ها را به محل SAF/USB انتخاب‌شده منتقل می‌کند؛ ضبط مستقیم سخت‌افزاری روی فلش بدون واسطهٔ گوشی هنوز پیاده نشده است.
- انتخاب خروجی «نوبا» در زهره مسیر نرم‌افزاری است؛ پخش واقعی صدا از اسپیکر به اتصال صوتی سخت‌افزار نهایی نیاز دارد.
- برخی فرمان‌های صوتی آفلاین فعلاً تشخیص داده می‌شوند ولی همهٔ آن‌ها هنوز به عمل سخت‌افزاری متصل نشده‌اند.
- اگر backend امنیتی فعال نباشد، رمز در AsyncStorage همان گوشی به‌صورت fallback نگه‌داری می‌شود؛ برای رمز واقعاً مشترک بین نسخه‌ها باید هستهٔ امنیتی backend در دسترس باشد.
